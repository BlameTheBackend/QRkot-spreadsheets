# QRkot-spreadsheets

Проект для сервиса поддержки котиков. Здесь есть API для работы с проектами, пожертвованиями, пользователями и генерацией отчётов.

## Что делает проект

- создаёт и хранит проекты и пожертвования;
- проверяет, что сумма пожертвований и проектов рассчитана корректно;
- управляет пользователями и авторизацией;
- закрывает проекты, когда собраны нужные средства;
- строит Excel-отчёт по закрытым проектам;
- загружает отчёт в Яндекс Диск и отдаёт публичную ссылку.

## Основные возможности

- работа с проектами через CRUD и API;
- работа с пожертвованиями и распределением средств;
- система проверки бизнес-правил;
- генерация таблицы с итоговой строкой;
- экспорт отчёта в Excel;
- интеграция с Яндекс Диском.

## Технологии

- FastAPI
- SQLAlchemy
- SQLite
- Pydantic
- XlsxWriter
- httpx
- Alembic

## Требования

- Python 3.12
- виртуальное окружение
- доступ к Яндекс Диску через токен

## Установка

1. Создайте виртуальное окружение:

   ```bash
   python -m venv venv
   ```

2. Активируйте его:

   ```bash
   source venv/Scripts/activate
   ```

3. Установите зависимости:

   ```bash
   pip install -r requirements.txt
   ```

4. Создайте файл `.env` и задайте переменные:

   ```env
   YANDEX_DISK_TOKEN=your_token_here
   ```

## Запуск приложения

```bash
uvicorn app.main:app --reload
```

После запуска приложение будет доступно по адресу:

```text
http://127.0.0.1:8000
```

## Основные маршруты

- `/charity_project` — проекты;
- `/donation` — пожертвования;
- `/auth` — авторизация и пользователи;
- `/yandex/report` — генерация Excel-отчёта.

## Генерация отчёта

Чтобы создать отчёт, нужно отправить POST-запрос на endpoint:

```http
POST /yandex/report
```

Требуется авторизация суперпользователя.

В ответ вернётся публичная ссылка на Excel-файл в Яндекс Диске.

## Структура проекта

- `app/main.py` — точка входа приложения;
- `app/core/` — настройки, база данных, пользователи, API-клиент;
- `app/models/` — модели SQLAlchemy;
- `app/schemas/` — Pydantic-схемы;
- `app/crud/` — работа с данными;
- `app/services/` — бизнес-логика и генерация отчётов;
- `app/api/` — маршруты и валидация;
- `tests/` — тесты проекта.

## Важные моменты

- в проекте есть проверка бизнес-правил для сумм и статусов закрытия проектов;
- файл отчёта создаётся в памяти, затем сохраняется на Яндекс Диске;
- итоговая строка в Excel содержит общее количество проектов;
- результатом API является публичная ссылка на файл.

## Примечание

Если вы запускаете проект локально, обязательно проверьте, что:

- используется правильный Python и venv;
- `.env` содержит корректный `YANDEX_DISK_TOKEN`;
- в системе есть доступ к интернету для обращения к Яндекс Диску.
